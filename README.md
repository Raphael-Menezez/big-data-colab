# Análise de Dados e Big Data em Python 📊🐍

Projeto prático desenvolvido no ambiente Google Colab durante a disciplina de Big Data do curso de Ciência da Computação.

## 🚀 Objetivos e Funcionalidades

- **Processamento de Dados:** Leitura, manipulação e tratamento de dados utilizando bibliotecas nativas e específicas de Python.
- **Análise Exploratória:** Aplicação de conceitos de análise de dados e estatística descritiva para extração de insights.
- **Ambiente Colaborativo:** Notebook interativo documentado e estruturado para execução em nuvem via Google Colab.

## 🛠️ Tecnologias Utilizadas

- **Python 3**
- **Google Colab**
- **Pandas / NumPy** *(ajuste conforme as bibliotecas que usou na aula)*
